# Picardly Android-Updates

Signierte ARM64-Testversionen von Picambo. Hier liegen ausschließlich Installationsdateien und Änderungshinweise; kein Quellcode.

APK unter Releases herunterladen und auf Android öffnen. Nach der erstmaligen Installation können neue Versionen direkt über die App abgerufen werden. Kein GitHub-Konto erforderlich. Testversionen, noch nicht im Google Play Store veröffentlicht.
